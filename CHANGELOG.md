# Changelog

## v1.0 RC2 — Visual system refinement

- Adopted the finalized two-line Harbor mark across the shell, favicon, and application icon.
- Migrated all user-visible components from legacy raw colours to the semantic Alpine token system.
- Refined Snow and Deep Ocean themes, pre-hydration theme resolution, typography, surfaces, cards, forms, dialogs, and charts.
- Rebuilt desktop and mobile navigation with a consistent Lucide outline icon system and current-page semantics.
- Added compact Snow, Deep Ocean, and System appearance previews plus responsive and reduced-motion coverage.
- Business functionality, financial definitions, persistence, routes, and Beacon analysis are unchanged.

## v1.0 RC1.1 — Identity acceptance hotfix

- Restored deep-link and reload routing for `#settings`, making Settings → Profile reliably accessible.
- Added an explicit Profile action in the application header, a clear Save changes action, and an inline success confirmation.
- Strengthened the rendered Harbor lockup size and acceptance coverage.
- Changed the empty profile identity to the neutral “User” state.

## v1.0 RC1 — Identity & Branding

- Added a persistent, repository-backed local profile with display name, optional full name, private avatar, base currency, time zone, language, and theme preference.
- Added compatibility normalisation for pre-RC1 workspace aggregates without changing financial records.
- Added initials avatar fallback, validated local image uploads, and profile-derived dashboard/sidebar identity.
- Added the geometric Harbor mark and light, dark, and favicon assets.
- Added semantic Snow, Glacier, Ocean, Mountain Slate, Pine, Amber, and Risk tokens with intentional light and dark mappings.
- Established typography, surfaces, spacing, radii, shadow, focus, and reduced-motion foundations in `DESIGN_SYSTEM.md`.

## Phase 4 — Beacon

- Added a plugin-oriented analyzer pipeline independent from presentation code.
- Added a transparent seven-dimension Financial Health Score.
- Added structured findings, financial risk detection, and data-derived recommendations.
- Added explainability for calculations, analyzed records, confidence, savings, and lifestyle impact.
- Added a unified Beacon timeline across forecast events, low points, recoveries, and recommendations.
- Added 30/90/180/365-day historical transaction analytics with explicit data limitations.
- Replaced Dashboard placeholder opportunities with live Beacon intelligence.
- Added the dedicated Beacon workspace and navigation entry.

## Phase 3 — Forecasting

- Added recurring subscriptions and commitments with shared recurrence logic.
- Added deterministic 30/60/90-day cash forecasting and static dated FX conversion.

## Phase 2 — Financial core

- Added persisted account and transaction workflows plus the core finance engine.
