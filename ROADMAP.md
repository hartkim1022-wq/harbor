# Harbor roadmap

## Completed

- Phase 1: product shell and financial-position dashboard.
- Phase 2: persisted accounts, transactions, and core finance engine.
- Phase 3: recurring records and deterministic 30/60/90-day forecasting.
- Phase 4: Beacon intelligence pipeline, health scoring, risks, explainable recommendations, timeline, and historical windows.

## Next

- Snapshot history for first-class net-worth, commitment, subscription, and runway trends.
- Scenario planning and user-controlled assumptions, kept separate from deterministic forecasts.
- Data import and reconciliation workflows before any banking integration.
- Optional PostgreSQL repository implementation behind the existing contract.

Authentication, conversational AI, Open Banking, Plaid, and TrueLayer remain intentionally out of scope.
